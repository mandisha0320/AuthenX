Data Flow
Client  →  Flask Route  →  File Validation  →  Model Inference  →  Confidence Score  →  MongoDB  →  JSON Response

Video path: Upload → OpenCV 1fps → batch frames → mean probs → {prediction, confidence, frames}
Text path: Headline → sanitize → DDG search → MiniLM encode → cosine sim → {prediction, sources}
